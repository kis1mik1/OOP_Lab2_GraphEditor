# Проверка лабораторной работы № 2

Отмечайте пункты после запуска приложения на компьютере с .NET 10 SDK.

## Обязательные пункты

- [ ] Окно запускается без исключений.
- [ ] Кнопка «+ Прямоугольник» создаёт прямоугольник.
- [ ] Кнопка «+ Эллипс» создаёт эллипс.
- [ ] Инструмент прямоугольника рисует его мышью.
- [ ] Инструмент эллипса рисует его мышью.
- [ ] Рисование из правого нижнего угла в левый верхний работает.
- [ ] Одновременно видны несколько фигур.
- [ ] По нажатию выбирается фигура под курсором.
- [ ] При пересечении выбирается верхняя фигура.
- [ ] Перемещение фигуры мышью работает.
- [ ] Все восемь маркеров изменяют размеры в ожидаемом направлении.
- [ ] Размер при перетаскивании маркера не становится отрицательным.
- [ ] Удаляется только выделенная фигура.
- [ ] Цвет заливки изменяется.
- [ ] Цвет границы изменяется.
- [ ] Толщина границы изменяется.
- [ ] Выделение хорошо заметно.
- [ ] Некорректный код цвета показывает сообщение и не меняет свойства.

## Дополнительные пункты

- [ ] Дублирование создаёт отдельную фигуру с сохранением свойств.
- [ ] На передний/задний план меняет и отображение, и порядок выбора.

## Проверка преподавателем

- [ ] Структура классов понятна.
- [ ] Все методы можно объяснить.
- [ ] Все пять принципов SOLID можно объяснить на примерах.
