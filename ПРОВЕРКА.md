# Проверка лабораторной работы № 2

## Результат проверки 11 ноября 2026 года

Проверена рабочая копия на основе коммита `642464f` после локальных исправлений.
Среда: Debian 13, .NET SDK 10.0.404, Avalonia 12.1.4.

- `dotnet restore` — зависимости восстановлены.
- `dotnet build` — сборка без ошибок и предупреждений.
- `dotnet build -c Release` — сборка без ошибок и предупреждений.
- `dotnet run --project Checks/ModelChecks.csproj` — 26 проверок моделей прошли.
- `dotnet run` — окно открыто на виртуальном X11-дисплее Xvfb.

Первый запуск без дисплея завершался `XOpenDisplay failed`. Затем был настроен
отдельный виртуальный дисплей и проверено настоящее окно приложения: события мыши
и клавиатуры отправлялись через X11, результат сверялся по изображениям и пикселям
фигур. Это проверка интерфейса, а не только вызов методов моделей.
Проверены размеры окна 1150×740 и 840×560, масштаб 100%.

Ниже отмечены выполненные проверки в этой среде. На компьютере для защиты
следует повторить сценарии из следующего раздела.

## Обязательные пункты

- [x] Окно запускается без исключений при наличии X11-дисплея.
- [x] Кнопка «+ Прямоугольник» создаёт прямоугольник.
- [x] Кнопка «+ Эллипс» создаёт эллипс.
- [x] Инструмент прямоугольника рисует его мышью.
- [x] Инструмент эллипса рисует его мышью.
- [x] Обе фигуры рисуются во всех четырёх направлениях от начальной точки.
- [x] Одновременно видны несколько фигур.
- [x] По нажатию выбирается фигура под курсором; пустое место снимает выделение.
- [x] При пересечении выбирается верхняя фигура.
- [x] Пустой угол ограничивающего прямоугольника эллипса не закрывает фигуру под ним.
- [x] Перемещение обеих фигур мышью работает.
- [x] Все восемь маркеров обеих фигур меняют соответствующие стороны.
- [x] Размер при перетаскивании не становится отрицательным и ограничен минимумом 10×10.
- [x] У фигуры 10×10 можно растянуть каждый из восьми маркеров: выбирается ближайший.
- [x] Случайный щелчок и рисунок шириной или высотой меньше 10 единиц не оставляют фигуру.
- [x] Удаляется только выделенная фигура.
- [x] Цвет заливки изменяется.
- [x] Цвет границы изменяется.
- [x] Толщина границы изменяется, в том числе может быть нулевой.
- [x] Выделение и маркеры видны.
- [x] Некорректный код цвета показывает сообщение и не меняет свойства.
- [x] Ввод альфа-канала и названий цветов отклоняется согласно формату #RRGGBB.
- [x] Действия без выделения не создают и не удаляют другие объекты.
- [x] При уходе за край холста фигура не рисуется поверх кнопок.
- [x] После скрытия окна при перетаскивании и отпускания кнопки движение без нажатия не перемещает фигуру.
- [x] В минимальном размере окна статус доступен, панель свойств и подсказки прокручиваются.

## Дополнительные пункты

- [x] Дублирование создаёт отдельную фигуру со смещением 20×20 и сохранением свойств.
- [x] Перемещение и удаление копии не меняют оригинал.
- [x] На передний/задний план меняет отображение и порядок выбора.

## Сценарии повторения перед защитой

| Шаг | Действия | Ожидаемый результат |
| --- | --- | --- |
| 1 | Выполнить команды сборки и запуска из README. Нажать обе кнопки добавления. | Видны две фигуры; последняя выделена. |
| 2 | Для каждого инструмента протянуть мышь вправо-вниз, влево-вниз, вправо-вверх и влево-вверх. | В каждом случае фигура находится между начальной и конечной точками. |
| 3 | В режиме рисования щёлкнуть без движения, затем нарисовать полосу шириной около 5 единиц. | Слишком маленькие объекты удаляются после отпускания кнопки. |
| 4 | Выбрать фигуру и потянуть за центр. | Положение меняется, размер сохраняется. |
| 5 | Последовательно потянуть все четыре угловых и четыре боковых маркера у обеих фигур. | Углы меняют две стороны, боковые маркеры — одну. Противоположные стороны остаются на месте. |
| 6 | Потянуть нижний правый маркер за верхний левый, затем растянуть правый боковой маркер. | Размер ограничен 10×10; правый маркер меняет ширину, а не высоту. |
| 7 | Задать заливку #FF0000, контур #008000 и толщину 8, затем 0 и 20. | Меняется выбранная фигура; при нуле контура нет. |
| 8 | Ввести неверный цвет, например #GG0000 или #80FF0000. Затем ввести верную заливку и неверный контур. | Сообщение об ошибке; прежние свойства целиком сохраняются. |
| 9 | Перекрыть красный прямоугольник синим эллипсом и щёлкнуть пересечение. | Выбирается верхний объект. Пустой угол эллипса пропускает щелчок к нижнему объекту, если там нет маркера выделения. |
| 10 | Выбрать нижний объект за открытую часть и переместить на передний, затем на задний план. | Меняются отрисовка и порядок выбора. |
| 11 | Дублировать обе фигуры с изменённым стилем. Сдвинуть и удалить копию. | Копия сохраняет размеры и стиль, оригинал остаётся на месте. |
| 12 | Щёлкнуть пустой холст, нажать удаление, дублирование, изменение порядка и применение свойств. | Нет исключений и изменений рисунка; для свойств и порядка появляется просьба выбрать объект. |
| 13 | Во время перетаскивания увести указатель за холст. Скрыть окно, отпустить кнопку и вернуться. | Кнопки не перекрываются рисунком; фигура не продолжает двигаться без нажатия. |
| 14 | Уменьшить окно до минимального размера и прокрутить панель справа. | Сообщения, свойства и подсказки доступны. |

## Границы проверки

Проверено настоящее приложение на Linux/X11 с программным дисплеем. Запуск
на Windows, macOS, Wayland, другом масштабе экрана и с обычным оконным менеджером
не проверялся. На компьютере преподавателя нужно повторить демонстрацию.
Сохранение рисунков и отмена действий не входят в реализованные возможности.
