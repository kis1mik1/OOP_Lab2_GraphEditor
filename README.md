# Лабораторная работа № 2 — графический редактор

Простейший векторный графический редактор на C# и Avalonia UI. Основа структуры — практическая заготовка преподавателя из ветки `graph-editor-base` репозитория `Patr1arch/spindly-ghost`.

## Запуск

Требуется .NET 10 SDK. Откройте папку проекта в IDE или терминале и выполните:

```bash
dotnet restore
dotnet build
dotnet run
```

## Возможности

- Прямоугольники и эллипсы создаются кнопками или рисованием мышью.
- Можно выбирать, перемещать и удалять фигуры.
- Выбранная фигура имеет восемь маркеров изменения размера.
- Цвет заливки, цвет контура и толщина контура настраиваются справа.
- При пересечении выбирается верхняя фигура.
- Дополнительно: дублирование и изменение порядка фигур.

## Работа с редактором

1. Кнопки «+ Прямоугольник» и «+ Эллипс» создают готовые фигуры.
2. Кнопки «Рисовать ...» позволяют протянуть фигуру мышью по холсту.
3. Нажмите «Выбор», чтобы выделить фигуру, перетащить её или потянуть за один из восьми маркеров.
4. Чтобы изменить свойства, выделите фигуру, введите цвета в формате `#RRGGBB` и нажмите «Применить».
5. Используйте «Удалить», «Дублировать», «На передний план» и «На задний план» для соответствующих действий.

Цвет задаётся ровно шестью шестнадцатеричными цифрами после `#`, например `#FF8000`.
Толщина границы — от 0 до 20; при 0 контур не рисуется.
Ошибочный цвет не меняет свойства фигуры. Сообщение находится под кнопкой «Применить».
В небольшом окне правая панель прокручивается.

Рисовать можно в любом направлении. Случайный щелчок или фигура меньше 10 единиц
по одной из сторон удаляется после завершения рисования. Маркеры также не позволяют
уменьшить размер ниже 10. Если зоны нескольких маркеров пересекаются, выбирается
ближайший к указателю. Видимая часть фигуры ограничена холстом.

## Устройство программы

- `Models/IShape.cs` — общий интерфейс фигуры.
- `Models/ShapeBase.cs` — общие свойства, перемещение и размеры.
- `Models/RectangleShape.cs` и `Models/EllipseShape.cs` — конкретные фигуры.
- `Models/CanvasDocument.cs` — список фигур, выделение и порядок.
- `Controls/DrawingSurface.cs` — холст, отрисовка и работа мышью.
- `Controls/DrawingTool.cs` — режимы инструментов.
- `MainWindow.axaml` — внешний вид интерфейса.
- `MainWindow.axaml.cs` — обработчики кнопок и изменение свойств.

Порядок фигур задаётся порядком элементов списка: последние отображаются выше предыдущих.

## Проверка

Простые проверки моделей запускаются без графического окружения:

```bash
dotnet run --project Checks/ModelChecks.csproj
```

Это небольшая консольная программа без отдельной тестовой библиотеки. Она проверяет
геометрию, перемещение, изменение размеров, выбор верхней фигуры, копирование,
удаление и порядок объектов. При ошибке выполнение завершается исключением.
Эти проверки не заменяют проверку кнопок и мыши.

Результаты проверки и сценарии повторения находятся в [ПРОВЕРКА.md](ПРОВЕРКА.md).
Объяснения к защите — в [ПОДГОТОВКА_К_ЗАЩИТЕ.md](ПОДГОТОВКА_К_ЗАЩИТЕ.md).

Для обычного запуска нужен графический рабочий стол. В Linux без доступного
X11/Wayland-дисплея приложение не откроется, даже если сборка прошла.
Сохранение рисунков в файл в этой лабораторной не предусмотрено: после закрытия
окна рисунок теряется.
